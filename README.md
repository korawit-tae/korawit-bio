# 🌐 Personal Bio Link Website

เว็บไซต์ Bio Link ส่วนตัว สไตล์แฟนตาซีจีนโบราณ (Dark Fantasy Style) สำหรับรวมช่องทางการติดต่อ Social Media และเพลงประกอบเว็บ พร้อมนำขึ้นระบบ Vercel

🌐 **Live Demo:** [https://korawit-bio.vercel.app](https://korawit-bio.vercel.app)
---

### ✨ Features
- 🎨 **Dark Fantasy UI/UX:** ออกแบบหน้าตาเว็บโทนเข้ม มู่เต๋า/แฟนตาซีจีน
- 🎵 **Background Music Player:** ระบบเล่นเพลงประกอบอัตโนมัติ (เพลง 莫问归期 - 蒋雪儿)
- 🔗 **Social Links:** รวมลิงก์ติดต่อหลัก (GitHub, Instagram, Facebook, YouTube, Discord, Email)
- 📱 **Responsive Design:** รองรับการแสดงผลทั้งบนคอมพิวเตอร์และมือถือ
- ⚡ **Fast Deployment:** Deploy และ Host บน Vercel
